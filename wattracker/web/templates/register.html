This server is not accepting new accounts.

Registration is open only while the server has no account at all — and even then it takes the one-time setup token the server prints when it starts — so that a new install can be set up by whoever started it. After that it stays closed unless it is turned on deliberately — an account here can change the app-wide AI provider settings, so an open sign-up page on a network is a way in.

If this is your server and you want to add another account, start it with WATTRACKER_ALLOW_REGISTRATION=1 set in the environment, create the account, then restart without it. For example: 

WATTRACKER_ALLOW_REGISTRATION=1 python -m wattracker
