Connector devices

A connector is the small app you run on the machine where Zwift is installed. It gives this server access to that machine’s Zwift folders and Bluetooth trainer, so the two halves can live on different computers. If you run wattracker and Zwift on the same machine, you do not need one.

A device token is a password. Anyone holding one can read and write your training data. It is stored here only as a hash, so it is shown once and cannot be recovered — revoke and re-pair if you lose it.

How to reach this from your phone (Tailscale)

By default wattracker listens only on this machine. Tailscale puts your devices on a private network and fronts this app with HTTPS, so it works away from home and the connection is encrypted. If instead you only want the app on your phone at home, bind it to your network and list the names it answers to — see “Reaching the server from other devices” in the README. Full version, including troubleshooting, is in docs/calendar-feed.md.

  1. Install Tailscale on this machine and your phone, and sign in to both.
  2. Find this machine’s tailnet name — run tailscale status and take the first line’s full name, like macbook.tail1a2b3c.ts.net.
  3. Tell wattracker that name and restart it, so the link it creates carries a hostname your phone can resolve: 
    export WATTRACKER_PUBLIC_HOST=macbook.tail1a2b3c.ts.net
./stop.sh && ./start.sh
    Read at startup, so the restart is required. Put the export in your shell profile to survive a reboot.
  4. Front it with HTTPS: tailscale serve --bg {{ request.url.port or 8000 }}. Undo later with tailscale serve reset.
  5. Come back here on this machine and press the button above. Over the tailnet, buttons that change something return 403 — the HTTPS front end changes the scheme and port the same-origin check compares — so generate and rotate links here. (On a plain LAN bind there is no mismatch and buttons work from a phone.) Copy the link immediately — it is shown once.
  6. On iOS: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar, and paste it. Send yourself the link the way you would a password.

One thing this does not cover: anyone on your tailnet can reach this whole app, not just the feed — Tailscale ACLs are the access control. The live-ride page does work over the tailnet, and over a LAN name: its origin check reads the same list of names this server answers to.

Backups

Backups are full snapshots of the database and therefore cover all users’ data, not just yours. They are taken automatically before every schema migration and once a day; you can also trigger one now. The newest 10 daily, 10 pre-migration, 5 manual, and 5 pre-restore backups are kept.

Restore is done offline via the command line — never while the server is running (that corrupts the database). Stop the server, then run:

FTP, Zwift ID, and folder paths are private to your account. The LLM settings (provider, model, API key) are app-level (shared) and the app is fully functional without them — LLM refinement is optional. Environment variables (API_KEY, LLM_ENDPOINT, LLM_MODEL, WATTRACKER_SECRET) override stored values; ANTHROPIC_API_KEY is the legacy name for API_KEY.
