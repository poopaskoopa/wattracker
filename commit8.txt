Android: address code review findings for #197

Addresses 14 review findings across performance, concurrency, lifecycle,
and UI state management:

1. Parallel reads: Launch detail and streams reads concurrently using
   `scope.async`.
2. Cloud waking state: Reset `isWaking` on `load()`; re-trigger reads on
   `ON_RESUME` and release ride data on `ON_STOP`.
3. View Model scoping & keying: Key detail VM on active source so VMs don't
   accumulate in two-pane mode or hold previous rider summaries.
4. Pull-to-refresh: Wrap empty/waking/error states in scrollable containers
   so pull-to-refresh works in both single-pane and two-pane modes.
5. Invalidation safety: Validate paired device before `invalidateActivityObjects`
   and clamp tombstone revisions.
6. Cancellation handling: Propagate `CancellationException` in `readResult` and
   ensure `isLoading = false` in `finally`.
7. Honest error panels: Render `DeviceStatePanel` (removed/unpaired) and
   `ThrottledPanel` rather than raw error messages.
8. Chart rendering optimization: Compute `StreamSeries.all` once and
   `remember` plot paths/layouts.
9. Row formatting optimization: Format date into `RideSummary` on read
   rather than per row composition.
10. Typed route arg: Use `NavType.IntType` for `{activityId}`.
11. Accessibility: Set back button content description to "Back".
12. Legend state: Key hidden series set on current ride streams.
13. Unit tests: Add unit test cases for unchanged revision caching, reload/release
    lifecycle, and waking state resets (218 total tests passing).
14. Cleanup: Remove unused strings and fix KDoc comments.
